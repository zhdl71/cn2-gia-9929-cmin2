## 三网优化到底是哪三条线，两种实现别混着看

商家宣传里的“三网优化”至少有两种完全不同的做法，标签一样，路由不一样。

**第一种：三家各接一条精品线。** 电信走 CN2 GIA，联通走 AS9929（CUII，联通 A 网），移动走 CMIN2（AS58807）。三家各走各的快车道，互不抢资源。这是最常被宣传的口径，也是成本最高的一种组合，三条线要分别向三家运营商买带宽。

**第二种：三网回程统一收敛到 CN2 GIA。** 去程电信联通走 CN2 GIA、移动走 CMI，回程三家全部落回 CN2 GIA。移动用户实际用的不是 CMIN2，而是电信的精品网。这种方案在中国电信方向上体验最稳，联通和移动靠 CN2 承载，晚高峰表现同样比 163 好，但严格说只有一条精品线在干活。

还有第三种，也是市场上最常见的一种：只优化其中一两家。比如只买 CN2 GIA 给电信，联通移动走普通线路；或者只买 AS9929，其余不管。这类产品同样会挂“优化线路”的牌子。

判断方法只有一个：看回程路由，不看宣传词。买之前拿到测试 IP，用 `mtr -T -P 22` 这类 TCP traceroute 打一下，看最后一跳落在哪个 AS 号上。CN2 GIA 认 AS4809，联通精品网认 AS9929，移动精品网认 AS58807。ICMP 被屏蔽的机器（SixtyNet 住宅系列就是）普通 ping 和 tracert 都测不出来，必须换 TCP 方式，否则你看到的全是超时。

## 晚高峰能到多少毫秒，怎么自己验证

洛杉矶机房到国内的物理距离摆在那里，正常情况下三网延迟落在 **150–200ms** 区间。同期第三方测评给出的数字可以当参照：一个主打三网回程统一 CN2 GIA 的洛杉矶方案实测晚高峰 150–180ms，另一家主打三网各接精品线的方案本地三网 ping 在 160–200ms。跨太平洋线路做不到更低，谁家宣传“80ms 到洛杉矶”基本可以关掉页面。

晚高峰（20:00–23:00）掉不掉速，取决于线路有没有独立链路和 QoS 保障。普通 163 线路在这个时段国际出口拥堵，速度掉到白天的三分之一、丢包率上到 5% 以上都是常态。精品线能把这个概率压下来，但没有任何线路能保证 100% 无波动，机房带宽和商家超售程度同样影响结果。“不掉速”是相对说法，别当成 SLA。

SixtyNet 有个特殊情况：官方屏蔽了 ICMP，常规 ping 测不出延迟。想在下单前验证，可以按这三步来：

1. 找官方页面或客服要测试 IP，别用论坛里别人贴的地址，归属经常搞错。
2. 用 `tcping` 或 `mtr -T -P 22` 打 SSH 端口，晚高峰和白天各测一轮，看丢包和抖动，不只是看平均值。
3. 实在拿不到测试 IP，就开最小档月付跑一周，用 `traceroute` 确认回程落在哪个 AS，再决定要不要转年缴。

## 常见问题

**晚高峰真的不掉速吗？**
精品线降低的是拥堵概率，不是消除波动。CN2 GIA 和 9929 走独立链路，晚高峰丢包率明显低于 163，但机房带宽、超售程度、国际出口状态都会影响结果。真要确认，按前面说的 TCP traceroute 方法在晚高峰自己测一轮。

**三网优化对电信、联通、移动哪个提升最明显？**
SixtyNet 这套组合里，联通走 AS10099 + AS9929，是三条里最接近标准精品网的；电信走 CN2 直连，去回程都干净；移动去程直连、回程落到 CN2，比 163 好但拿不到 CMIN2。移动宽带用户如果只认 CMIN2，得换商家。

**月付还是年缴？**
先用月付验证 IP 质量和晚高峰表现，确认没问题再年缴，年缴省约 17%。反过来做，遇到 IP 不干净或者路由不符预期，退款规则还不一定原路退回。

**IP 被封了怎么办？**
官方对住宅 IP 产品做了端口屏蔽和外部探测拦截，本身就是为了降低被封概率。真的遇到 IP 不可用，走工单处理，具体换 IP 的费用和周期以客服回复为准，官网没有公开统一政策。

**支持哪些付款方式？**
官网标价以美元计，国内用户下单前确认结算页支持的支付渠道，不同计费周期可能不同。
